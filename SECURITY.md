# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in PayGate, report it privately:

- **Email:** help@paygatex402.com
- **Expected response:** acknowledgment within 48 hours

Please do not open public GitHub issues for security vulnerabilities.

## Scope

- x402 payment flow (402 challenge, EIP-3009 verification, facilitator settlement)
- API gateway and seller endpoints
- Earnings ledger and dashboard

Out of scope: third-party infrastructure (Circle, Supabase, Arc RPC providers).
